# Ubuntu apt パッケージメモ

`.Brewfile.ubuntu` から除外したパッケージのうち、apt で入れるもの。

## Shell & Terminal

```bash
sudo apt install zsh tmux
```

## CLI Utilities

```bash
sudo apt install bat eza fd-find ripgrep zoxide tree watch wget curl jq parallel telnet nkf
```

- `bat` → コマンド名は `batcat`、`alias bat=batcat` 推奨
- `fd-find` → コマンド名は `fdfind`、`alias fd=fdfind` 推奨

## Git & Version Control

```bash
sudo apt install git git-delta git-lfs gh
```

## Programming Languages & Runtimes

```bash
sudo apt install python3 python3-pip
# Rust: rustup (https://rustup.rs)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Deno: 公式スクリプト
curl -fsSL https://deno.land/install.sh | sh
```

## Development Tools

```bash
sudo apt install direnv ruby-build
```

## Build Tools

```bash
sudo apt install autoconf automake bison cmake libtool pkg-config re2c protobuf-compiler
```

## Database & Data Tools

```bash
sudo apt install mysql-client redis-tools sqlite3
```

## Container (Docker 公式リポジトリ)

```bash
# https://docs.docker.com/engine/install/ubuntu/
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## Image Processing

```bash
sudo apt install imagemagick ghostscript
```

## Text & Data Processing

```bash
sudo apt install jq xq
# yq (mikefarah版) は snap or バイナリ直接取得
# snap install yq
```

## System Utilities

```bash
sudo apt install cabextract genisoimage wimtools dnsmasq
```

  libssl-dev libicu-dev
